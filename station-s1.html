Automatische Schraubstation (ASS)

Automatic Screw Station (ASS)

Die Automatische Schraubstation (ASS) wurde fuer Bosch Ungarn zur Verschraubung von Motorgehaeuseteilen entwickelt. Sie fuehrt zwei Verschraubungen mit einer Spindel durch, vollautomatisch und NC-gesteuert (CS351 Einkanalsystem von Bosch Rexroth). Die ASS ist die einzige vollstaendig einsatzbereite Station bei Projektbeginn und hat im Vorprojekt ProData bereits 5.000 Schraubbeobachtungen beigetragen. Daten werden als JSON ueber FTP aufgezeichnet. Messgroessen: Drehmoment, Drehwinkel, Zeit und Gradient.

The Automatic Screw Station (ASS) was developed for Bosch Hungary to fasten motor housing parts. It performs two fastenings with one spindle, fully automatic and NC-controlled (Bosch Rexroth CS351 single-channel system). The ASS was the only fully operational station at project start and has already contributed 5,000 screw observations in the ProData predecessor project. Data is recorded as JSON via FTP. Measurements: torque, angle, time and gradient.
